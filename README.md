# AVIS METAL — сайт

Статичний односторінковий сайт. Без збірки, без залежностей — відкривається як є.

```
web/
├─ index.html        одна сторінка, весь текст тут
├─ css/style.css     палітра, типографіка, анімації
├─ js/main.js        скрол-анімації, лайтбокс, форма
├─ img/              26 фото з ваших матеріалів
└─ README.md
```

Локальний перегляд: просто відкрийте `index.html` у браузері.
Публікація: залийте всю папку `web/` на будь-який хостинг (Netlify, Vercel, звичайний FTP).

## ⚠ Що ОБОВ'ЯЗКОВО замінити перед публікацією

### 1. Телефон і e-mail
Зараз стоять заглушки. У `index.html` знайдіть:

```html
<a class="link link--big" href="tel:+420000000000">+420 XXX XXX XXX</a>
<a class="link link--big" href="mailto:info@avismetal.cz">info@avismetal.cz</a>
```

Замініть **обидва** — і текст, і `href`. E-mail також у `js/main.js`, змінна `FORM_EMAIL`.

### 2. Відгуки клієнтів
Я **не вигадував** відгуки. Замість них — чотири заглушки з жовтою позначкою
`ukázkový text — nahradit`. Це:

- один великий відгук у синій смузі (після блоку послуг)
- три відгуки в секції `#reference`

Що зробити з кожним:
1. замінити текст усередині `<span data-placeholder>…</span>`
2. замінити ім'я та локацію в `<footer>`
3. **видалити** `<span class="ph-chip">ukázkový text — nahradit</span>`
4. прибрати атрибут `data-placeholder` (він робить текст напівпрозорим)

Поки заглушки стоять — сайт публікувати не варто.

### 3. Соцмережі
У футері три посилання з `href="#"` — Facebook, Instagram, WhatsApp.
Поставте справжні URL або видаліть зайві рядки.

### 4. Форма поптавки
Зараз форма без сервера: після заповнення вона відкриває поштовий клієнт
з готовим листом. Працює одразу, але виглядає не дуже.

Щоб приходило на пошту нормально — зареєструйтесь на
[formspree.io](https://formspree.io) (безкоштовний тариф) і впишіть
свій endpoint у `js/main.js`, перший рядок налаштувань:

```js
var FORM_ENDPOINT = 'https://formspree.io/f/ВАШ_КОД';
```

Після цього fallback на пошту вимкнеться сам.

## Що варто перевірити (я брав з фото, могло не збігтися)

У секції **Realizace** підписи до фото я склав з того, що видно на знімках.
Перевірте формулювання і локації — особливо:

- «Rodinný dům na klíč — Ústecký kraj»
- «Zateplení bytového domu»
- «Výkop u památkového objektu»
- «Obklady bazénové haly»

Якщо якийсь об'єкт насправді інший — просто відредагуйте `<figcaption>`
і атрибут `data-cap` у відповідної `<figure class="gal__i">`.

Також у тексті «O nás» я написав «7 let» (з 2019) і «14 profesí» — цифри
рахуються анімацією з атрибутів `data-count`. Якщо хочете інші — правте там.

## Дизайн — коротко

**Палітра** (усе в `:root` на початку `style.css`):

| змінна | колір | де |
|---|---|---|
| `--ink` | `#0E0E0F` графіт | базовий темний фон |
| `--bone` | `#F4F1EA` кістка | світлі секції |
| `--amber` | `#E5AE38` жовтий | кнопки, лінії, цифри, акценти |
| `--steel` | `#1B3243` глибока синь | смуга з відгуком, градієнти |
| `--sky` | `#8FB4CC` голуба | теги, дрібні деталі |

Змінити фірмовий колір = змінити одне значення у `:root`.

**Шрифти:** Fraunces (заголовки, serif) + Inter (текст) з Google Fonts.
Якщо треба працювати офлайн — завантажте їх локально і замініть `<link>`.

**Морф-анімації:**
- фото при появі — з овальної форми в прямокутник (`clip-path`)
- фото при наведенні — кути «розтікаються» в радіус 26px + легкий зум
- текстові посилання — верхній рядок їде вгору, знизу заїжджає копія з нахилом
- кнопки — заливка піднімається знизу, змінюючи форму з дуги на прямокутник
- курсор — жовта клякса, що постійно змінює форму; над фото збільшується і пише «zvětšit»

Усе вимикається автоматично при `prefers-reduced-motion` в системі.
